# Commercial licensing

Wellspent (Timer) offers two licensing paths for project-owned code:

- **Open source:** use the software under the GNU Affero General Public License,
  version 3 only (`AGPL-3.0-only`). The full terms are in [LICENSE](LICENSE).
  Commercial use is allowed under those terms without purchasing another license.
- **Commercial:** purchase a separate written agreement from the project owner
  for proprietary use requiring permissions beyond those granted by the AGPL.
  The agreement defines the covered code, versions, permitted uses, fees, and any
  support or update commitments.

This document describes the commercial licensing option; it does not itself grant
a proprietary license or waive any AGPL obligations. Unless you have an applicable
commercial agreement, the open-source license governs project-owned code.

## Inquiries

Contact the maintainer through the
[repository's GitHub issues page](https://github.com/benschac/timer/issues)
with a commercial licensing inquiry. Include a brief description of the intended
use and request a private contact channel for confidential details.

## Third-party components

A commercial agreement can grant rights only to code the licensor owns or has
permission to license on those terms. It does not replace third-party licenses
or waive their obligations. Existing component, file, dependency, and asset
notices continue to apply, including:

- [Live Activity module: MIT](apps/mobile/modules/timer-live-activity/LICENSE)
- [Liquid UI: MIT](packages/liquid-ui/LICENSE)
- [ThreeUI marketing code: MIT](apps/web/app/marketing/threeui/LICENSE)
- [Bundled fonts: SIL Open Font License 1.1](apps/web/public/marketing/fonts/LICENSE.md)

This list identifies existing repository notices, not an exhaustive dependency
audit. Before issuing a commercial agreement, the maintainer must verify the
rights and third-party obligations for the exact code and dependencies covered.

## Contributions

External contributions require review of commercial relicensing rights before
merge. See [CONTRIBUTING.md](CONTRIBUTING.md). No additional rights are assumed
merely because someone submits a pull request.
